# TraqOOH Brand Assets

## Color Palette
| Token | Hex | Usage |
|-------|-----|-------|
| Primary Blue | `#2563eb` | Buttons, links, active states |
| Dark Navy | `#0f172a` | Page backgrounds |
| Light Gray | `#f3f4f6` | Page background (main) |
| Orange Accent | `#f97316` | Highlights, badges |
| Green Success | `#22c55e` | Vacant status, success states |
| Red Error | `#ef4444` | Errors, Booked status |
| Amber Warning | `#f59e0b` | Vacant Soon status |

## Typography
- **Display/Headings**: System UI / Inter (bold, extrabold)
- **Body**: Inter, 14–16px
- **Labels**: Inter uppercase, letter-spacing 0.1em

## Logo Usage
- App icon: Blue gradient square with white "t"
- Wordmark: `traqOOH` — lowercase "traq", uppercase "OOH"

## Place assets here:
- `assets/logo.svg` — main logo SVG
- `assets/logo-dark.svg` — dark background version
- `assets/favicon.ico`
- `assets/og-image.png` — 1200×630 Open Graph image
- `assets/mockups/` — UI screenshots and mockups
